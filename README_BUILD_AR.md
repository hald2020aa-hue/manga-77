# Manga XW Clean — مشروع أندرويد مستقل

نسخة قراءة نظيفة ومستقلة مستوحاة من **وظائف** التطبيق الذي قدمه المستخدم للفحص. المشروع ليس تفكيكًا قابلًا للبناء للكود الأصلي، ولا نسخة معدّلة من حزمته؛ لا يتضمن مكتبات إعلانات أو مشتريات أو كود السحابة الأصلي. اسم الحزمة الجديد `com.mangaxw.clean`، لذا يمكن تثبيته بجانب التطبيق الأصلي دون الكتابة على بياناته.

## ما تم تنفيذه في كود المشروع

- إدارة مواقع المصدر: إضافة، تعديل، حذف، وفتح عنوان موقع مباشرة.
- قبول عناوين HTTP وHTTPS الصالحة، بما فيها أسماء النطاقات العربية الدولية، دون قوائم حظر للمواقع أو عناوين الأعمال داخل البرنامج. تُرفض بروتوكولات `javascript:` و`file:` لأسباب أمنية فقط.
- متصفح داخلي مع سجل تنقل ومكتبة محفوظات.
- فلترة أسماء نطاقات إعلانية معروفة ومنع عدد من عناصر إعلانات الصفحات بعد التحميل. لا يوجد Ad SDK في المشروع.
- محاولة استخراج صور الفصل الظاهرة في HTML بما فيها بعض الصور المؤجلة، دون موصلات/مزوّدات خاصة بكل موقع.
- قارئ صفحات عمودي وأفقي، وتحكم بالتكبير.
- تنزيل صور الفصل إلى ملفات خاصة بالتطبيق، وفتح الفصول المنزلة دون إنترنت.
- تصدير/استيراد مصادر المواقع والمكتبة والسجل بصيغة JSON من واجهة النظام.
- واجهة عربية داكنة مع لمسات ذهبية.

## طريقة البناء في GitHub — الأسهل

1. أنشئ مستودع GitHub جديدًا أو فرعًا مستقلًا. لا ترفع مجلد المشروع داخل مجلد إضافي؛ يجب أن يظهر `settings.gradle` في جذر المستودع.
2. ارفع **كافة محتويات هذا المجلد** بما فيها `.github/workflows/android.yml` (تأكد من ظهور المجلد المخفي `.github`).
3. افتح تبويب **Actions** ثم workflow باسم **Android APK** واختر **Run workflow**، أو ارفع التغييرات إلى `main`/`master` لتبدأ العملية تلقائيًا.
4. بعد نجاح التشغيل افتح صفحة الـ workflow، ثم **Artifacts**، وحمّل `Manga-XW-Clean-debug`، وستجد `app-debug.apk` داخله.
5. ثبّت APK على أندرويد كبرنامج جديد. هذه نسخة `debug` للاختبار، وليست نسخة إطلاق موقعة بمفتاح توزيع خاص بك.

## طريقة البناء باستخدام Android Studio

1. اختر **File > Open** وافتح مجلد `Manga_XW_Clean_Rebuild`، لا ملف ZIP نفسه.
2. تحتاج إلى Android SDK 35 وJDK 17 وGradle 8.9. إذا طلب Android Studio مسار Gradle لأن هذا التسليم لا يتضمن Gradle Wrapper ثنائيًا، اختر تثبيت Gradle 8.9 محليًا أو استخدم مسار GitHub Actions أعلاه.
3. نفّذ **Sync Project**، ثم **Build > Build APK(s)**. المسار المتوقع `app/build/outputs/apk/debug/app-debug.apk`.
4. لا تغيّر معرف الحزمة إلى `org.hamak.mangareader`؛ إبقاؤه مستقلًا يمنع تعارض التوقيع والبيانات.

## تحقق وظيفي بعد البناء

1. أضف `https://example.org` وتحقق أن فتح الرابط يعمل.
2. احفظ صفحة في المكتبة، ثم أعد فتحها من المكتبة والسجل.
3. افتح فصلًا يحتوي على صور فعلية واضغط **استخراج الصفحات**. إذا لم يُعثر على الصور، جرّب التمرير وفتح الفصل مباشرة؛ بعض المواقع لا تسمح باستكشاف صورها بهذه الطريقة.
4. نزّل الفصل، أوقف الإنترنت، وافتحه من تبويب التنزيلات. لا تغلق التطبيق أثناء تنزيل الصور؛ التنزيل هنا ضمن عملية التطبيق وليس خدمة نظام ثابتة.
5. صدر JSON من الإعدادات، ثم استورده للتحقق من عودة المصادر والمحفوظات.

## حدود التنفيذ

- **النسخة ليست مطابقة للبرنامج الأصلي**: لا تشمل جميع محركات الموقع أو موصلات المزودات الأصلية، أو الحسابات والمجتمع والسحابة، أو وظائف الدفع. لا يمكن نقل قاعدة بيانات التطبيق الأصلي مباشرة بمجرد تثبيت هذا المشروع.
- قبول أي موقع يعني فتحه كصفحة WebView، **ولا يعني بالضرورة استخراج المانجا تلقائيًا من كل موقع**. بعض المواقع تستخدم JavaScript مخصصًا أو Cloudflare أو مصادقة أو قيودًا على الخادم، ولا يلتف البرنامج حول هذه الضوابط.
- حظر الإعلانات الموجود هنا أفضل-جهد، ولا يضمن حذف كل إعلان داخل مواقع الطرف الثالث (خاصة الإعلانات المستضافة من نفس نطاق الموقع).
- دعم HTTP متاح للروابط القديمة لكنه غير مشفر؛ يفضّل استخدام HTTPS.
- ملف JSON لا يحوي ملفات صور الفصول المنزّلة، وليس بديلًا عن نسخها احتياطيًا.
- **لم يُشغَّل Android Gradle Build في بيئة إعداد هذا المشروع**؛ تمت مراجعة صياغة Java وXML فقط. نجاح البناء ونتائج الوظائف يتطلبان اختبار Android Studio أو GitHub Actions.

## هيكل المشروع

- `app/src/main/java/com/mangaxw/clean/MainActivity.java` الواجهة والمكتبة والمصادر والنسخ.
- `BrowserActivity.java` المتصفح وتجميع الصور.
- `ReaderActivity.java` عرض الصفحات في الوضعين.
- `DownloadUtil.java` تنزيل الصور الخاصة.
- `AdFilter.java` حجب شبكات الإعلان المعروفة.
- `AppStore.java` حفظ البيانات محليًا والتحقق من المواقع.
- `ChapterExtractor.java` منطق تجميع صور الفصول.
- `REVERSE_ENGINEERING_REPORT_AR.md` نتائج فحص ملف APK الأصلي وحدودها.
- `original_class_inventory.txt` قائمة أسماء أصناف التطبيق الأصلية المستخرجة من DEX.

**الاستخدام مسؤولية المستخدم وبما يحترم حقوق نشر المحتوى وشروط المواقع.**
